# Interactive Markdown Studio

A lightweight, browser-based **Markdown Editor & Live Previewer** built with vanilla HTML, JavaScript, and Tailwind CSS.

## 🚀 Features

- **Side-by-Side Live Preview:** Real-time markdown parsing with `Marked.js`.
- **Code Syntax Highlighting:** Beautiful code snippet styling using `Highlight.js` with Sky Blue highlights.
- **LocalStorage Auto-Save:** Content persists even after browser refresh.
- **Export Capabilities:** 
  - Copy raw rendered HTML directly to clipboard.
  - Download raw content as a `.md` file.
- **Responsive Dark Mode UI:** Styled using Tailwind CSS.

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS (CDN)**
- **JavaScript (ES6+)**
- **Marked.js** (Markdown Parsing)
- **Highlight.js** (Code Highlighting)

## 💻 Local Setup

1. Clone this repository or download the files.
2. Open the project folder in VS Code.
3. Use the **Live Server** extension or directly open `index.html` in any modern web browser.
